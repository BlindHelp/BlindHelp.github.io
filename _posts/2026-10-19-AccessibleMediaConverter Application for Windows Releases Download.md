Je viens de découvrir qu'il existe une application pour Windows appelée AccessibleMediaConverter complètement accessible, c'est un nouveau convertisseur audio/vidéo accessible pour Windows, ci-dessous je colle le lien de téléchargement.    

Voici la petite description de l'application déjà mentionnée faite par l'auteur lui-même.

Accessible Media Converter est un outil gratuit et pilotable au clavier sous Windows, conçu spécifiquement pour être utilisé avec des lecteurs d'écran comme NVDA.    

## Fonctionnalités principales

* Conversion audio et vidéo : prise en charge de nombreux formats courants (notamment vidéo vers MP4 et MKV, et conversion audio vers audio).    

## Lien pour télécharger l'application pour Windows appelée AccessibleMediaConverter

Télécharger le programme d'installation (Setup) version 1.20.6 (celui-ci était le numéro de version lorsque j'ai publié ledit article à propos de cette application)    
<https://github.com/math65/accessible-media-converter/releases/latest/download/AccessibleMediaConverter-Setup.exe>    
Dans tous les cas, en cliquant sur ce même lien permettra de télécharger la dernière version actuelle de l'application pour Windows appelée AccessibleMediaConverter.    

## Dépôt sur GitHub

<https://github.com/math65/accessible-media-converter/>    

## Pour nos amis programmeurs

Pour cloner le dépôt depuis  GitHub utilisez la commande git suivante:    
`git clone https://github.com/math65/accessible-media-converter.git`    

Et pour conclure, je voulez vous dire que cette application Windows appelée [AccessibleMediaConverter](https://github.com/math65/accessible-media-converter/) est  le compagnon idéal de l'autre application Windows appelée [DownAccess](https://github.com/math65/downaccess/), créée par le même auteur, qui, une fois installés, peuvent fonctionner ensemble.
