# TranslateVideo

TranslateVideo est un logiciel Windows permettant de traduire en français le contenu parlé d’une vidéo ou d’un fichier audio.    

Le programme analyse la langue entendue, transcrit les paroles, les traduit en français, génère une voix française puis l’intègre au fichier d’origine. Le résultat peut être enregistré sous la forme d’une vidéo ou d’un fichier audio.    

TranslateVideo a été conçu avec une attention particulière portée à l’accessibilité et à l’utilisation avec les lecteurs d’écran, notamment NVDA.    

## Principales fonctions

### Traduction de vidéos YouTube

TranslateVideo peut traiter une vidéo à partir de son adresse YouTube.    

Il tente d’abord d’utiliser les sous-titres disponibles sur YouTube. Lorsqu’aucune piste exploitable n’est trouvée, le programme télécharge le son de la vidéo et utilise son propre système de reconnaissance vocale.    

### Traduction de fichiers locaux

Il est également possible de sélectionner un fichier déjà présent sur l’ordinateur.    

TranslateVideo peut notamment traiter des fichiers :    

* vidéo ;
* audio ;
* MP3 ;
* WAV ;
* OGG ;
* MP4 et autres formats reconnus par le moteur multimédia.

### Détection automatique de la langue

Le programme analyse chaque passage afin d’identifier sa langue.    

Les langues actuellement prises en charge pour la traduction vers le français sont :    

* l’anglais ;
* l’espagnol ;
* l’italien ;
* l’allemand ;
* le néerlandais.

Un même fichier peut contenir plusieurs langues. Les passages déjà prononcés en français peuvent être conservés sans traduction.    

### Transcription automatique

Lorsque les sous-titres ne sont pas disponibles, TranslateVideo utilise un moteur de reconnaissance vocale local basé sur Whisper.    

Cette transcription permet de :    

* repérer les passages parlés ;
* identifier leur langue ;
* établir leur position dans le fichier ;
* préparer leur traduction vers le français.

### Traduction locale

La traduction est réalisée directement sur l’ordinateur à l’aide de modèles spécialisés.    

Après leur premier téléchargement, les modèles peuvent être réutilisés sans avoir à être téléchargés pour chaque traitement.    

Le moteur comprend des protections destinées à détecter :    

* les traductions anormalement longues ;
* les répétitions de mots ou de phrases ;
* les résultats incohérents par rapport au texte original ;
* les voix françaises qui nécessiteraient une accélération excessive.

Lorsqu’une traduction paraît incorrecte, le programme peut tenter automatiquement une nouvelle génération avec des paramètres plus stricts.    

### Création d’une voix française

Chaque passage traduit est lu par une voix française installée sur Windows.    

L’utilisateur peut choisir :    

* la voix utilisée ;
* la vitesse de lecture ;
* le niveau sonore de la piste originale pendant les passages traduits.

La voix française est ensuite placée aux moments correspondant aux paroles d’origine.

### Conservation de l’ambiance sonore

TranslateVideo ne remplace pas entièrement la bande-son.    

La musique, les bruitages et l’ambiance du fichier original sont conservés. Pendant les passages traduits, le volume de la voix originale est réduit afin que la voix française reste compréhensible.    

Le niveau de la piste originale peut être réglé dans les options.    

### Sortie vidéo ou audio

Le résultat peut être enregistré sous plusieurs formes.    

#### Sortie vidéo

Le programme peut créer une vidéo traduite en français, notamment au format MP4.    

Selon la source, différentes résolutions peuvent être proposées, par exemple :    

* 480p ;
* 720p ;
* 1080p ;
* qualité automatique.

#### Sortie audio

Il est également possible d’extraire uniquement le résultat sonore.    

Les formats disponibles peuvent comprendre :    

* MP3 ;
* OGG ;
* WAV.

Cette fonction est pratique pour écouter une conférence, un tutoriel, un entretien ou un podcast sans conserver l’image.    

## Interface accessible

TranslateVideo est utilisable au clavier et a été conçu pour fonctionner avec NVDA.    

L’interface principale permet notamment de :    

* saisir une adresse YouTube ;
* sélectionner un fichier sur l’ordinateur ;
* lancer ou annuler un traitement ;
* suivre la progression ;
* choisir le dossier de destination ;
* ouvrir le fichier créé ;
* ouvrir le dossier contenant les résultats.

Un menu accessible avec la touche F10 donne accès aux principales fonctions, aux options, à l’aide et aux informations sur la version du programme.    

## Suivi de la progression

Pendant le traitement, TranslateVideo indique les différentes étapes en cours :    

* préparation de la source ;
* téléchargement éventuel ;
* transcription ;
* détection des langues ;
* traduction ;
* création des voix françaises ;
* assemblage ;
* mixage final.

La progression générale est affichée sous forme de pourcentage. Des signaux sonores peuvent également accompagner son évolution afin de faciliter le suivi avec un lecteur d’écran.    

## Réglages mémorisés

Le programme peut conserver les principaux choix de l’utilisateur, notamment :    

* le dossier de sortie ;
* le type de résultat souhaité ;
* le format audio ou vidéo ;
* la résolution ;
* la voix française ;
* la vitesse de la voix ;
* le volume de la bande-son originale.

Les modèles de reconnaissance et de traduction déjà téléchargés sont également conservés lors des mises à jour.    

## Mise à jour du logiciel

TranslateVideo peut vérifier si une nouvelle version est disponible.    

Les mises à jour sont conçues pour conserver :    

* les réglages ;
* les modèles téléchargés ;
* les fichiers produits ;
* le dossier de sortie choisi.

## Exemples d’utilisation

TranslateVideo peut notamment servir à écouter en français :    

* un tutoriel informatique en anglais ;
* une démonstration en espagnol ;
* une conférence étrangère ;
* un entretien ou un podcast ;
* une vidéo contenant seulement quelques passages dans une autre langue ;
* un long fichier audio enregistré sur l’ordinateur.

## Fonctionnement local et connexion Internet

La reconnaissance vocale, la traduction et la création de la voix française sont réalisées localement sur l’ordinateur.    

Une connexion Internet reste nécessaire pour :    

* télécharger une vidéo YouTube ;
* télécharger les modèles lors de leur première utilisation ;
* vérifier et récupérer les mises à jour.

Une fois les modèles installés, les fichiers locaux peuvent généralement être traités sans transmettre leur contenu à un service de traduction en ligne.    

## Limites actuelles

TranslateVideo réalise une traduction automatique. Le résultat peut varier selon :    

* la qualité du son ;
* le bruit de fond ;
* le nombre de personnes qui parlent simultanément ;
* les accents ;
* les termes techniques ;
* les noms propres ;
* la présence de musique très forte ;
* la qualité des sous-titres disponibles.

Le logiciel ne remplace pas un doublage professionnel. Son objectif est de rendre un contenu étranger rapidement compréhensible en français, tout en conservant autant que possible le rythme et l’ambiance du document original.    

## Configuration

TranslateVideo est destiné à Windows 64 bits.    

Les traitements de reconnaissance vocale et de traduction utilisent le processeur de l’ordinateur. Leur durée dépend notamment :    

* de la longueur du fichier ;
* de la puissance de la machine ;
* du nombre de passages à traduire ;
* de la présence ou non de sous-titres exploitables.

Le premier traitement peut être plus long en raison du téléchargement et de l’installation des modèles nécessaires.
